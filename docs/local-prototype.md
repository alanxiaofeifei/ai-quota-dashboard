# 本地只读原型

当前原型保存并展示浏览器扩展导出的额度摘要，不查询平台后台、不上传数据。前台读取已得到用户的字段一致性确认；后台自动采集、真实账户 RPC、Android 访问、提醒和 Sites 部署仍未启用。

## Windows 使用

1. 在本项目最新成功的 GitHub Actions 中下载 `ai-quota-dashboard-Windows`，解压到新目录后双击 `ai-quota-dashboard.exe`。升级时先退出旧程序，不要混合新旧包的文件；已有本机数据库继续沿用。界面已嵌入程序，最终用户无需安装 Node、Python 或 Rust；请保留下载包中的许可声明及第三方源码目录，重新分发时一并提供。
2. 默认浏览器会打开 `127.0.0.1` 的随机本地端口并完成本次授权。这是本机网站，尚未发布在线站点。原型阶段请保留程序的控制台窗口；关闭程序即停止服务，托盘体验留待后续阶段。
3. 本包已经包含 `browser-extension/`：在 Chrome／Edge 的扩展页面加载这个子目录，不要加载 exe 所在根目录。旧扩展需重新加载新版；详情见[扩展步骤](browser-selection.md)。包内 `START-HERE.txt` 和看板中的“使用帮助”都提供操作说明。
4. 创建本地账户别名。在已登录的官方 [Usage 页面](https://chatgpt.com/settings/usage?tab=overview) 手动刷新并读取额度，核对后点击扩展“复制摘要”。回到看板点击“粘贴摘要”，按 Ctrl+V，再确认导入到当前别名。程序不会主动读取剪贴板。
5. 也可以在扩展下载摘要 JSON，再通过看板“导入网页摘要”选择该文件。不要导入程序包的 `THIRD_PARTY_MANIFEST.json` 或 `SOURCE_MANIFEST.json`；它们不含额度数据。

别名仅用于本地归档，不表示已校验平台登录身份。扩展导出没有账户身份，因此不能自动判断文件属于哪个账户；导入前必须选择正确的别名。不同别名各保留最新快照，删除别名会同时删除它的快照。

当前流程为“用户点击读取 → 复制或下载摘要 → 本地导入”，没有扩展直推、平台轮询或无人值守更新。“重载本机记录”只重新读取已保存的记录，不查询平台；更新需重新读取官方页。未接入的平台保持暂不可用，不生成演示额度。

## 数据状态

- 网页读取时间和导入时间分别保存，后导入的旧文件不会变成新观测。
- 超过 15 分钟的观测标为过期；即使刚读取，服务端更新时间仍为未知。
- 相对重置估计从网页读取时间计算，不从导入时间重新计时。时间到达只提示预计已重置、需要重新读取，不把比例改成满额。
- credits 是独立的订阅加购余额。零 credits 不代表周额度为零；未知值也不会替换成零。若显示未知，请在官方页面重新选择 Credits 标题下的数字余额后再读取，不能只选标题。
- 同一观测重复导入保持幂等；旧观测、同时间但内容冲突的文件不能覆盖最新快照。

## 本地授权与存储

程序只监听 `127.0.0.1`，不开放 LAN 或 Android 入口。启动链接使用两分钟内有效的一次性 fragment 授权值，界面接收后立即清除地址栏中的 fragment；程序不会把它打印到控制台。

后续本地请求使用 HttpOnly 会话 Cookie 和应用自己的短期请求校验值，会话最多八小时并随进程结束失效。`sessionStorage` 只保存该应用的短期校验值，不保存平台 token 或额度记录。授权窗口丢失或会话过期时，先退出旧程序，再重新启动打开新窗口；无需提供或复制任何平台凭据。

SQLite 默认位于当前用户的操作系统本地应用数据目录，文件名为 `quota.sqlite`。Windows 默认路径为 `%LOCALAPPDATA%\AIQuota\AIQuotaDashboard\data\quota.sqlite`。数据库只保留本地别名和白名单摘要，不保存原始选中文字、原始 JSON、Cookie 或聊天。

这是单个本机所有者的原型，不是公共多用户服务。自定义数据目录应由当前用户控制并限制访问；不要把数据库、备份或真实摘要放入源码仓库，也不要把本地监听地址通过隧道直接公开。

## 开发构建

开发构建使用仓库固定的 Rust 1.99.1 和 Node.js 22.12 或更新的 22.x。在仓库根目录依次运行：

```sh
npm --prefix web ci
npm --prefix web test
npm --prefix web run build
cargo build --locked --release --bin ai-quota-dashboard
```

前端构建产物在编译时嵌入程序。原有 `ai-quota-preflight` 离线工具可在未构建界面时继续使用；看板程序如果未包含前端则拒绝启动。

CI 下载包另附项目和第三方许可声明、适用的第三方源码、`SOURCE_MANIFEST.json` 功能源码指纹及 `SHA256SUMS` 程序哈希；这些是分发附件，界面运行不依赖它们。构建者应保留并随再分发提供相关许可与源码附件。

仅开发诊断时可用 `--data-dir <绝对目录>`、`--port <端口>` 和 `--no-open`，查看完整参数可运行 `ai-quota-dashboard --help`。`--no-open` 不输出授权令牌，不能作为获取裸访问链接的办法；它也不会改变只监听本机的限制。

## 升级、回滚和卸载

- 升级前退出程序，再复制整个本地数据目录作为一致性备份。保存对应版本的可执行文件和源码提交；备份留在用户控制的私有位置。
- 当前数据库 schema 为版本 1。无法识别的未来版本或非本项目数据库会被拒绝，不会被清空或自动覆盖。未来迁移须另行提供验收和恢复步骤。
- 回滚时退出程序，恢复相匹配的旧程序和数据库备份；只回退可执行文件不保证能读取新版数据库。
- 卸载时退出程序，删除可执行文件，并按需要删除本项目的数据目录及浏览器标签中的本地应用会话。此操作不涉及官方客户端或其登录态。

通用核心、锁文件和构建流程保留在 GitHub，并按[交付说明](delivery.md)同步到私有核心备份。Sites 和其他托管平台只承担后续部署角色，不是源码唯一存放处。
